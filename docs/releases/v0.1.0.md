# hypoxiapipe v0.1.0

Initial public research-software release.

- Reproducible cohort ingestion and a separate longitudinal TCGA-PRAD biochemical-recurrence endpoint; the existing TCGA-CDR PFI cohort remains distinct.
- Fixed Smith20 signature scoring with patient matching before cohort-relative standardisation, plus survival-model evaluation and repeated nested validation.
- Frozen `prad-bcr-star-smith20-cox-v1` research model trained on 483 TCGA-PRAD GDC STAR expression-matched patients and 97 BCR events after 60-month censoring.
- Single- and multi-sample CLI and FastAPI inference using frozen preprocessing; relative hazard, Smith20 score, linear predictor, percentile, and provenance only.
- Checksum-verified model bundles, manifests, Docker API image, readiness endpoint, known-prediction smoke test, and CI checks.

Breaking changes: none; this is the initial public release.

Scientific and product limits: the predictor requires the locked GDC-compatible STAR TPM, `log2(TPM + 1)`, HGNC-symbol input contract and all 20 Smith20 genes. It is retrospective, research-use software, not a clinical device. It does not provide calibrated absolute recurrence probabilities, clinical risk categories, or treatment recommendations. MSKCC, Cambridge, and Stockholm support the cohort-relative Smith20 prognostic association, **not** external validation of the frozen STAR-native predictor. **No independent STAR-compatible external validation of the frozen predictor.**
